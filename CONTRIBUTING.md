# Contributing

Pull requests are welcome. Before opening one:

1. **License:** the asset must be open-source with a permissive license (MIT,
   Apache-2.0, CC-BY-4.0, BSD, or public domain). No proprietary or
   source-available-only licenses.
2. **Real source:** link to the actual repo/file, not a reseller or mirror.
3. **One line, no hype:** describe what it does, not why it's the best. No
   emoji, no "revolutionary", no unverifiable claims.
4. **Right section:** add it under the matching category, alphabetically is
   fine but not required — this list is organized by usefulness, not vanity.
5. **Format:**
   ```md
   - [Name](https://github.com/...) — one-line, factual description. `LICENSE`
   ```

## Getting it verified

Entries here aren't individually tested before merge — that's what
[AI Assets Directory](https://aiassetsdirectory.com/submit) is for. If you want
your asset hand-tested, with an install guide and a "verified" badge, submit it
there instead (or in addition).
