# Contributing

Pull requests are welcome. Before opening one, make sure the entry:

- Is open-source under a permissive license: MIT, Apache-2.0, CC-BY-4.0, BSD, or
  public domain. No proprietary or source-available-only licenses.
- Links to the actual repo or file, not a reseller or a mirror.
- Has one honest, factual line describing what it does, not why it's the
  best. No emoji, no "revolutionary," no unverifiable claims.
- Goes under the matching category. Order within a category is by usefulness,
  not alphabetical order.

Format:

```md
- [Name](https://github.com/...) - One-line, factual description. (LICENSE)
```

## Getting it verified

Entries here aren't tested individually before merge. That's what
[AI Assets Directory](https://aiassetsdirectory.com/submit) is for: submit
there too if you want the asset hand-tested, with an install guide and a
verified badge.
